# Introduction

### Types of Functional Interface

1. `Predicate`
2. `Function`
3. `Consumer`
4. `Supplier`

This are prefined functional Interface made available by Java Team.

1. Included in `java.util.function`


### Example of old Interfaces which are Functional Interface before Java 1.8

1. `Comparable` contains single abstract method `compareTo()`

2. `Runnable` contains single abstract method `run()`

3. `callable` contains single abstract method `call()`

4. `ActionListener` contains single abstract method `actionPerformed()`


### New Functional Interface introduced in 1.8

Package `java.util.function`

`Predicate`
`Function`
`Consumer`
