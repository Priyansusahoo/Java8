# Introduction

### Types of Functional Interface

`Predicate`
`Function`
`Consumer`
`Supplier`

This are prefined functional Interface made available by Java Team.

Included in `java.util.function`


### Example of old Interfaces which are Functional Interface

`Comparable` contains single abstract method `compareTo()`

`Runnable` contains single abstract method `run()`

`callable` contains single abstract method `call()`

`ActionListener` contains single abstract method `actionPerformed()`


### New Functional Interface introduced in 1.8

Package `java.util.function`

`Predicate`
`Function`
`Consumer`
`Supplier`
